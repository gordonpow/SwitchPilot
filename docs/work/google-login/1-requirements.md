# 需求：GUI 內以瀏覽器（Google）登入新增帳號

## 目標

使用者不必在 claude 裡 `/login`、也不會影響目前登入的帳號，直接在 GUI 按一個按鈕，在乾淨的瀏覽器視窗用 Google（或 email）登入，就把該帳號新增成可切換的 slot。

## 使用者決定（2026-11-13）

- 登入完成後只新增，不切換。
- 使用 Edge InPrivate 視窗登入。
- 已同意實測 `claude auth login`（結果見規格「已確認的事實」）。

## 驗收條件

- **AC-1** GUI 帳號區有「新增帳號（瀏覽器登入）」按鈕；按下後開啟 Edge InPrivate 視窗到 Claude 授權頁。
- **AC-2** 登入期間 GUI 顯示登入中視窗，有「複製登入網址」與「取消」；取消會結束登入程序並清除暫存資料。
- **AC-3** 使用者在瀏覽器完成登入後（不需要回 GUI 貼任何東西），GUI 詢問帳號名稱（預設為 email），新帳號出現在清單。
- **AC-4** 整個過程不改動 `~/.claude/.credentials.json`、`~/.claude.json`，正在執行的 claude 不受影響。例外：登入的是目前使用中的同一個帳號時，同時更新目前的憑證並在事件紀錄提醒。
- **AC-5** 找不到 Edge 時改用預設瀏覽器開啟；超過 5 分鐘未完成視為逾時並清除。
- **AC-6** 登入成功但讀不到憑證或帳號資訊時，顯示錯誤並清除暫存資料。

## 不做的範圍

- 不支援 Chrome／Firefox 無痕視窗（只有 Edge InPrivate 與預設瀏覽器備援）。
- 不自動填入 Google 帳號。

## 限制

- 只用標準函式庫；介面文字繁體中文。
- 暫存登入目錄含權杖，任何結束路徑（成功、失敗、取消、逾時、GUI 關閉）都要刪除。
