# 需求：自動檢查更新

## 目標

使用者不用自己去 GitHub 看，App 有新版本時會提示，並能一鍵完成更新。

## 使用者決定（2026-11-15）

- 每 10 分鐘檢查一次；有更新時用紅點引導使用者更新。
- 自動下載並替換（portable exe 執行中被鎖，結束後由腳本替換並重新啟動，失敗還原）。
- 設定可選「包含預覽版」，預設包含。

## 驗收條件

- AC-1：App 啟動約 30 秒後檢查一次，之後每 10 分鐘檢查一次 GitHub Releases（`gordonpow/Switching_account`）。設定「自動檢查更新」可關閉（預設開啟）。
- AC-2：有比目前版本新、且附有 `.exe` 的 release 時：
  - 左側導覽「設定」與子項目「更新」出現紅點；
  - 每個新版本只跳一次系統通知。
- AC-3：設定「更新」頁顯示目前版本、最新版本、release 說明、上次檢查時間，以及「立即檢查」。
- AC-4：按「下載更新」下載 exe，顯示進度；下載完成後驗證大小（release 提供 SHA-256 時也驗證），失敗顯示原因並可重試。
- AC-5：下載完成後按「重新啟動並更新」：程式結束，腳本等程式完全結束後把舊 exe 備份為 `.old`、換上新版並重新啟動。替換失敗時還原舊版並啟動，記錄在 `~/.claude-switcher/updates/update.log`。
- AC-6：非 portable 執行（開發模式）時不提供替換，只提供「開啟 release 頁面」。
- AC-7：設定「包含預覽版」（預設開啟）；關閉時只比較正式版。
- AC-8：中英文介面；網路錯誤不影響其他功能，只在更新頁顯示錯誤。
- AC-9：既有測試通過；新增測試涵蓋版本比較、挑選 release、下載驗證、替換腳本參數。

## 不做

- 程式碼簽章驗證。
- 差異更新、降版。
- 安裝版（NSIS installer）。

## 限制

- 網路用 Electron `net.fetch`（使用者環境有 TLS 攔截）；請求不得帶個人資料，User-Agent 用通用名稱。
- 每次發布新版前必須提高 `app/package.json` 的 `version`，否則不會被視為更新。
- `*.ps1` 註解只能用英文。
