# 需求：背景執行、開機自動啟動、左導覽排版

日期：2026-11-14
使用者確認（AskUserQuestion）：主畫面採左側導覽＋右側內容；設定採左側分類（多級選單）；按關閉(X)縮到系統匣；開機自動啟動時直接在背景啟動。
使用者補充：帳號不要分 Claude／agy 兩頁（也不要依學校等用途分），全部都是「帳號」，依公司名稱分類（Anthropic、Google）。

## 目標

讓切換器能長時間在背景監控用量（不佔工作列、可開機自動執行），並把主畫面改成左側導覽、右側內容，消除大片空白；設定改為分類頁面。

## 驗收條件

### A. 背景執行

- **AC-1**：設定「一般」有開關「關閉視窗時縮到系統匣」（預設關）。開啟時按視窗 X：視窗隱藏、程式繼續執行（輪詢、自動切換照常），系統匣出現圖示；第一次隱藏時跳出通知「仍在背景執行」。關閉時按 X 結束程式（與現在相同）。
- **AC-2**：系統匣圖示：滑鼠停留顯示「Claude 帳號切換器」與目前帳號名稱；按一下（或雙擊）顯示並聚焦視窗；右鍵選單有「開啟視窗」「結束」。選「結束」會正常結束（走既有 dispose 流程）。
- **AC-3**：程式已在執行時再啟動一次 exe，不會開第二個實例，而是顯示並聚焦既有視窗。
- **AC-4**：點系統通知（例如自動切換通知）會顯示並聚焦視窗。

### B. 開機自動啟動

- **AC-5**：設定「一般」有開關「開機時自動啟動」（預設關）。開啟後登入 Windows 時自動執行本程式；關閉後不再自動執行。登錄的路徑是 portable exe 本身（不是每次解壓的暫存路徑）。
- **AC-6**：開機自動啟動時不顯示視窗，只出現在系統匣（不論「縮到系統匣」開關），用量輪詢與自動切換照常。從系統匣開啟視窗後，之後按 X 依 AC-1 的開關處理。
- **AC-7**：exe 搬移位置後重新開啟一次，自動啟動的登錄路徑更新為新位置（設定為開時）。

### C. 版面

- **AC-8**：主視窗左側固定導覽列，項目：總覽、帳號、Claude CLI、事件紀錄；下方分隔後為「設定」，展開後有子項目：一般、帳號切換、Claude CLI、自動整理上下文、模型分工、Claude Code 整合。點項目後右側只顯示該頁內容；目前所在項目有明顯標示。
- **AC-9**：「總覽」頁：全部額度用完警示（若有）、依公司分組的帳號用量／額度摘要、啟動 claude、自動切換狀態、最近事件。1280×820 下不需捲動即可看到大部分內容。
- **AC-10**：「帳號」頁只有一頁，依公司分組：「Anthropic」（Claude 帳號）與「Google」（agy 帳號），每組標題旁顯示該組帳號數。頁首一個「新增帳號」按鈕（或卡片），先選公司（Anthropic／Google）再走對應的登入或儲存目前登入流程。各組卡片用延展格線（寬度隨視窗填滿），不出現整列空白。介面不再出現「agy 帳號」「Claude 帳號」作為分頁名稱（卡片內可顯示產品名稱 Claude／agy 作為小標籤）。
- **AC-11**：設定與模型分工不再是對話框，而是右側的頁面；原本設定與模型分工的所有選項都保留且行為不變。頂端列的「設定」「模型分工」按鈕移除（改由導覽進入）。
- **AC-12**：視窗最小寬度 900 時版面不破版（導覽列可縮成只有圖示或維持窄寬度，內容可捲動）。

## 不做

- 系統匣選單中直接切換帳號（之後再說）。
- macOS／Linux 的對應行為。
- 改動任何帳號切換、輪詢、agy 的邏輯。

## 限制

- 介面文字繁體中文（台灣用語）。
- `src/core` 不得 import electron；開機啟動、系統匣在 `src/main/index.ts`，controller 以注入方式呼叫。
- 測試不得改動真實的登錄（`setLoginItemSettings`）或真實家目錄。
- 截圖驗證（`CLAUDE_SWITCHER_SCREENSHOT`）時不得建立系統匣、不得改登錄。
