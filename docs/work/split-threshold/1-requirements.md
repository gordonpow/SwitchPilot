# 需求：5 小時與每週用量門檻分開設定

使用者請求（2026-11-16）：「用量門檻分成五小時 還有一周的 可以分開調整」。行為明確，未另行確認 AC。

## 目標
自動切換的用量門檻，5 小時視窗與 7 天（每週）視窗可以各自設定。

## 驗收條件
- AC-1：設定的「自動切換」區塊有兩個滑桿：「5 小時門檻」「每週門檻」，範圍 50～100 %，各自儲存。
- AC-2：5 小時用量 ≥ 5 小時門檻，或每週用量 ≥ 每週門檻時，視為達門檻（自動切換、帳號是否可用、最早可用時間、重置卡恢復判斷、switcher-run 的 Claude 可用判斷都一致）。
- AC-3：舊設定只有 `threshold` 時，每週門檻沿用同一個值；`threshold` 仍代表 5 小時門檻（Python 版相容）。
- AC-4：帳號卡、總覽的用量條顏色與標示，各視窗依自己的門檻。
- AC-5：typecheck 與測試通過；新增分開門檻的測試。

## 不做
- 不支援 Opus／Sonnet 個別的週視窗門檻。
- 不改 agy 額度門檻。
